参数 对应内容
story 剧情构成（必填）
production 制作水平（必填）
character 人物塑造（必填）
atmosphere 氛围营造（必填）
enjoyment 个人主观感受（必填）
value 思想情感价值（可选，填 0 也会显示）
total 手动指定总分（可选）
title 辅助阅读标签（默认「动画评分」，不显示在卡片中）

所有分数均为 0–10，支持小数。同一篇文章可以插入多个组件。组件在构建时生成 HTML 和 SVG，无需额外脚本；支持博客明暗主题与窄屏排版。
